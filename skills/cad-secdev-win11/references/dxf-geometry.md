# DXF 图纸识别与标注算法：实战教训（FSCC 项目验证）

> 案例底座：汽车冲压焊接件图 FSCC111352.dxf（DXF 2013，约 17MB，模型空间 2.7 万实体），13 轮规则迭代 + 实体级人工验收收敛到 68 个标注。以下每条都有翻车实例背书。

## 第一步永远是结构探查，不要看图猜

写任何识别逻辑前，先用 ezdxf 只读 dump：
- 图层清单 + 每层实体类型计数；
- 各区域包围盒（本例：主视图在 x 490–780 / y 420–790，细节图在顶部，剖视图 R/A/B/C/X 在右/下）；
- 关键实体族的参数分布（半径、颜色、所在层）。

本例实测结构（每张新图都要重新实测，但探查维度不变）：
- 引线 = LEADER 实体（91 条，DIM 层）；球标圈 = CIRCLE（`from` 层，color 6 品红，r=4.5/6.0）；零件几何在 layer `1`；孔 ≈ r1.6 CIRCLE；腰槽端部 = ARC；归并标注 = 多条引线先汇聚到竖直合并线再接球标。

## ⚠️ LEADER 顶点存储方向不统一

- **现象**：假设 `vertices[0]` 是箭头端，一半引线指反。
- **处理**：按几何语义自动判别箭头端（tip）：更贴零件几何采样点、且离球标更远的一端：

```python
def tip_end(vs, geo_pts, balloons):
    a, b = vs[0], vs[-1]
    sa, sb = geo_count(a), geo_count(b)          # R=4.0 邻域内几何点数
    if sa != sb:
        return a if sa > sb else b
    return a if balloon_dist(a) > balloon_dist(b) else b
```

## ⚠️ 几何判定反直觉陷阱清单（每条都真翻过车）

1. **点到 LINE 的距离必须用点到线段距离**，不能用端点距离——贴在线段中段附近的点全被漏掉（曾致局部过滤 kept 0/107）。
2. **ray-segment 交点公式的分母符号**曾写反，表现为射线命中系统性地少一半方向。
3. **多边形包含判定（射线法）前，环点列必须按链序整理并对齐方向**——乱序点列的射线法结果全错（弧升级"缝合闭环"时踩过）。
4. **主方向拟合信直方图，不信内点率扫描**：方向直方图（mod 90° 按段长加权）取峰向+抛物线插值；用内点率扫角会被"斜框恰好卡进直角边界"作弊。精扫窗口 ±3°/±1.5° 都试过，都会被斜框顶到边界，最终完全信直方图。
5. **贴边吸附的边位置取最密集簇的众数均值**，不能对全部射线点取均值——双壁槽的射线点同时落内外两壁，总均值会把框整体带偏（G1 红框外偏的根因）。
6. **局部轨迹带宽**取 `max(90分位+1, 0.6×cap)`——固定带宽遇到偏心末端会剪掉远侧壁。轨迹后做 2 轮邻域中位数平滑去凸刺。
7. **阈值要按实测校准而不是直觉**：双壁壁距可以恰好是 0.499，所以壁厚下限必须 <0.5；外壁可能由两段断线拼成，"单线覆盖率=1.0"的检查会漏掉拼合壁（要支持 ±0.15 容差的断线拼接覆盖）。
8. **拼合/回环用端点网格索引**（eps≈0.8 缝合）+ DFS 回环；框尺寸约束外接对角线（如 [0.5, 250]）排除渲染小点和视图轮廓巨环。

## 拟合必漂移，本体必精确

- **教训**：用射线轨迹拟合出来的圆/矩形/圆角矩形标注，与人工认可的真值总有微小漂移（13 轮迭代后 G1–G8 的 8 个拟合标注仍全被人工删除）。
- **正解**：识别出"目标是什么类型"后，**优先搜索并复制图纸中已有的真实实体**作为标注。本例的 `find_inner_wall_rect`：4 条真实 LINE 围成、包含 tip、边覆盖自适应（rc=min(8, 0.35×短边)）、四边外侧有伴随壁线（同坐标 ±0.15 拼接覆盖 ≥80%）、相对外环面积 ≥12%——命中即复制本体，一次通过人工验收。
- 拟合只作为本体不存在时的兜底（回退存闭合轨迹 poly）。

## ⚠️ 去重聚类判据必须保守

- **现象**：用"环带交叠"做合并，误吞相邻槽的标记（G9 案例）。
- **正解**：合并只认三类保守判据——bbox 包含、中心距 ≤2、**中心深入对方环内（≤min(r)+0.5）**。
- 保留优先级排序：(封闭性优先, 触及档位, 弧最后, 尺寸小)。

## ⚠️ 结构规则 vs 人工意图：用豁免表，不要硬刚规则

- **现象**：按结构规则过滤"同心符号组"，17 个被过滤组里 16 个是用户特意保留的滚花沉孔——结构与噪声完全同构，规则无法区分。
- **正解**：维护人工豁免表（如 `MANUAL_EXEMPT_LEADERS={"25C85","282F6"}`），按**引线 handle** 豁免。注意：豁免条目要交叉核对其目标坐标（282F4 的目标是孔圆不是同组的 609，放错就错杀）。

## 升级链模式（识别兜底的层级设计）

弧目标的标注目标按三级升级，每级失败才走下一级：
1. 所在闭合环（触及 ≤2.3 或包含）——但**内层环资格**要求环外扩 1.0 后必须包住 tip：末端旁边的小盒/细长框即使 gap 很小也不是它的内侧线框（G10 曾被劫持成 4 实体碎片）；
2. 局部射线轨迹（半径 18，两遍过滤）——min 边 ≤4 被折断线截断时走"扁带救援"：从触弧 DFS 找包含 tip 的最小面积缝合闭环，**禁踩长度 ≤1.2 的径向短桥线**（否则内外线角部直连产生月牙环）；
3. 连通域（距 tip ≤8，段数 ≤24 防泄漏）。

尾部语义校验：tail_text 存 JSON，同组类型一致性校验（如 10X 组 = 数量 10 + 组号 G1–G10）。

## 人工标注样图的语义规律（同类图纸直接复用）

- 双壁槽（圆角外壁 + 内壁方框）→ 标**内壁方框**；
- 单壁圆角槽 → 标**跟随槽壁的圆角矩形**；
- 腰形槽 → 标**槽内轮廓闭合线**；
- 圆 → 标触及的圆本身（双箭头触及两个同心圆可各标一圈）。

## 验收闭环（每个图纸识别项目的固定动作）

```
analyze → mark → render + 三查（闭合性/交叠/漏标）
       → 与人工基准逐槽/逐实体比对 → 差异回写阈值/规则/豁免表 → 重复
```

- **配对用几何签名**（类型+中心+尺寸，tol≈1.2），**绝不用 handle**（SaveAs 后重排不可比）。
- 人工批改语义要读懂：人工修正常是"删除错误标注 + 保留正确样例"（v13 案例：删 15 个实体、零新增），先 diff 出"保留=正确样例"再提炼规则。
- 工具链固定四件套：导出基准（DWG→DXF）、签名配对验收、区域渲染 PNG、实体叠加可视化诊断。
- 每轮迭代记录：改了什么阈值、哪些案例由错变对、有没有引入新错（回归）。

## ezdxf 使用注意

- 版本差异实测：1.4.4 的 `ezpath.make_path()` 不支持 LEADER；`.vertices` 两版（1.1.4/1.4.4）都可用。用版本敏感 API 前先 `try` 探测。
- flatten 采样（`p.flattening(distance=0.3)`）再做射线法/距离判定，圆弧类一律先 flatten。
- 实体几何属性读取全部包 try/except——损坏/异型实体在真实图纸里常见。
- **DXF 中文文字=国标 SHX 大字体**（B-rep3转2 线回写 2026-10-14）：样式必须 `gbenor.shx` + bigfont `gbcbig.shx`；TTF（simsun.ttc）写法数据链路全对（COM 读回 TextString 中文完好、FontFile 字段正确）但 CAD 渲染层不吃、显示 ？??——生成端直接用 SHX 大字体，别拿"读回正常"当验证。
- **$EXTMIN/$EXTMAX 直写 header 会被覆盖**（ezdxf 1.4.4 实测）：saveas→update_extents() 会用布局属性把 header 赋值重置回哨兵；正解 `msp.dxf.extmin/extmax`（布局属性）。"写进去了"要重开文件验证才算数。

## ⚠️ OCC/BRep 几何算法教训（B-rep3转2 剖视图线，2026-10-16 回写）

1. **布尔切观察侧的切盒必须以实体包围盒中心为中心**：曾以剖切面参考点 P1 为中心——P1 可以离零件很远，零件顶端越出盒缘未被切，表现为断面缺 460mm² 剖面线、观察侧材料混入保留半、HLR 多出约 860 个幽灵实体。正解：盒边长取 2×包围盒对角线+10mm，d/t 两向以实体包围盒中心为中心，仅 s∈[−2L,0] 贴剖切面方向不变；修复后保留半体积、断面面积、剖面线总长三者交叉核对全绿。
2. **剖面线填充不走三角化/网格采样**：3转2 的精度根基="面直接投影为线"，符号性/示意性产物也不降精度口径。正解=断面边界取精确实体边、0.05mm 弦高离散、与 45° 线族求交后按半开区间奇偶配对（半开保顶点不重不漏）。交叉核对：剖面线总长 ≈ 断面面积÷间距（实测偏差 <1%）。
3. **细线验收别信视觉模型**：lw0.5 在 3.74px/mm 渲染缩放下是亚像素宽，视觉模型报"完全没有剖面线"还幻觉出不存在的文字。像素级程序检测先行（45° 对角连续性占比、剖面线带 vs 空白对照带密度），目检用高倍放大+加粗重渲染后再喂视觉模型。
