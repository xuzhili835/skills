# 扩展攻击库（attack-library）

正文第 3 节列出的是**每次必打**的核心对抗面；本文件是它的延伸弹药库——开工前随步骤 3 通读一遍，命中当前项目形态的就纳入本轮探针表。参考条目使用领域描述而非硬编码文档编号（各家指南版本间 ID 会漂移，引用时请到对应指南当版查证）。

## 使用与准入

- 本库条目来自公开测试指南与真实缺陷模式；新条目入内同样要过正文的三道闸（归轴→证据→去重），从头脑风暴长出来的不收。
- 项目专属的弹着点（确认为真 bug 后的最小复现探针）不放这里——放被测项目仓库的《回归校准单》，两份文件分工见各自文首说明。

## 身份与会话

| 探针思路 | 说明 |
|---|---|
| 对象级越权（IDOR 类） | 用低权账号遍历/猜解他人资源标识（顺序 id、uuid 泄露面），读、改、删各打一遍 |
| 直连后端绕过入口鉴权 | 经网关必拒的伪造内部信任头，打到内网服务端口观察是否被接受——通过则写进部署警告 |
| 会话固定/并发会话策略 | 同一账号两端同时登录的行为；登出一端另一端是否失效（是否有意设计需区分） |
| 忘记密码链路强度 | 重置凭据的可猜测性、尝试次数限制、链接/token 有效期与一次性 |

## 数据与输入

| 探针思路 | 说明 |
|---|---|
| 注入式输入 | SQL 关键词、模板语法、路径穿越串进各文本字段——判据是不出现 500 与异常回显 |
| 类型混淆 | 数值字段传字符串、布尔字段传数字、数组期望处给标量，观察校验层是否接住 |
| 分页/导出无上限 | page_size 给超大值诱导一次拉全量，看限流/截断是否存在 |
| 数字边界 | 负数量、负价格、超高精度小数、整数溢出值的下单/退款类操作 |
| 文件类字段 | 上传可执行后缀伪装图片、超大数据体、文件名携带路径符号 |

## 时序与并发

| 探针思路 | 说明 |
|---|---|
| 双写竞争 | 两会话同时抢最后一份库存/同一唯一键注册，断言只有一个成功且台账平 |
| 过期瞬间窗口 | 优惠/凭证在到期前一瞬提交，行为是否与声明的有效期口径一致 |
| 重复提交竞速 | 同一写操作连发 N 次，落库行数必须恰好 1 |

## 产品口径

| 探针思路 | 说明 |
|---|---|
| 计费/配额代理度量 | 榜单、统计、扣费所依据的埋点能否被普通用户操作低成本污染 |
| 提示词注入面（若含 LLM 功能） | 用户可控文本能否改写系统提示的行为边界 |
| 时区与本地化 | 跨时区时间戳展示/结算的口径一致性 |
