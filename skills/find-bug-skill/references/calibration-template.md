# 回归校准单（模板——复制到你自己的技能目录里填）

这份文件**只属于当前被测项目**：换一个项目就作废重攒。它回答一个问题——
"我用这套方法论在这个项目上找到过哪些真 bug？每一条未来如何用最小代价验证它没复发？"

## 用法

1. **第一轮找完 bug 就建表**：每个确认的问题一行，列「症状 / 最小探针 / 兜住它的规则」。
2. **规则名引用 SKILL.md 第 2/3 节的类目**，让探针和方法论挂钩，而不是一堆孤立脚本。
3. **修复合入后**：这就是最快的冒烟回归单（比全量业务流轻得多）；哪条探针 FAIL = 同类 bug 复发。
4. **新机制修进来时**：把机制背后的**规则**补进 SKILL.md 对应条目，再回这里追加探针记录——让下一轮永远站在上一轮的实锤之上。
