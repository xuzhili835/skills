# 风格 ground truth（蒸馏自真实文档定稿）

> 本文件即唯一依据：以下基准蒸馏自 2026-09-23 前后的真实定稿文档，原件已由用户清理。**不要寻找或读取任何源路径**，这里蒸馏出的文字就是标准。

## A. 技术方案/文档 —— 用户手改定稿即标准

（2026-09-23 用户在 AI 初稿上**纯删除**改定，自评"这个才叫精简"）

- 体裁定性：方法说明，不是汇报。用户删掉的全是对话残渣和汇报腔。
- 用户删掉的，以后不要再写：封面/色块/目录/页眉/版本标注与作者行版本号；项目背景与任务出处段；环境依赖台账；"验证结果""待确认问题""下一步计划"整节；过长论证（压成一两句）。
- 保留的骨架（2 页内）：标题 + 一行元信息（姓名 日期）→ 一、任务与数据（2 段）→ 二、方法（流程一段 / 选型一段 / 特征体系一段 / 判别规则 + 三线表 / 树原理一段）。
- 溯源预答保留：主动一句写清规则来源（全特征训练的决策树）与特征名为自命名（非行业标准）——读者是行家，会想知道这两点。
- 版式：黑白；黑体标题 / 宋体正文；首行缩进 480；行距 312；三线表（上下粗、表头下细、无竖线）；表题加粗居中。构建器直接用 references/docx_kit.js（参数即该验收版的参数）。

## B. 调研报告 —— 同事气质参照，不复刻格式

- Heading1 题目 / Heading2 "1." 章 / Heading3 "2.1" 节；宋体正文；适度加粗关键结论与数字；有图有表；段落长短不一、直陈。
- 每个人有自己的风格，格式细节不必复刻；学的是气质：直陈、有图有数、不绕。

## D. 研究院周报 pptx 版式 —— 周汇报模板 V2.0（2026-11-06 蒸馏）

> 模板主源 `实训文档\研究院\素材\周汇报模板V2.0.pptx`（16:9 13.33×7.5in，17 页；旧模板归档在同级 `归档_旧模板_2026-11-06\`）。**产出顺序（2026-11-06 用户定）：先按本模板出 ppt，word 由 ppt 产出**——ppt 是唯一主源，不再单独写 docx 再复制。

**页面结构（五节，目录页跟进度）**

- P1 封面：大标题 48pt（占位符）"XX项目周汇报" + 日期行 `2026.XX.XX——2026.XX.XX`（双横线连接）。
- P2 目录页（每节翻页后重复一页做进度页）：五个词条 24pt，**当前节红色 C00000，其余深蓝 002060**：1、周总结 / 2、XXA项目方面 / 3、XXB项目方面 / 4、XXC项目方面 / 5、下周计划。项目数按当期实际增删词条与细项页；**项目按求解器级划分**（2026-11-06 项目经理定：剖视图求解器=一个项目、内部模块不各立项目，与图框识别求解器区分）。
- 周总结页（每项目一段）：标题"XX项目上周进度总结"；**内容三要素照模板内嵌规范**——①项目状况简述（大目标、周期、预计效果；**不写"（长期）"这类模糊周期**，项目经理不认"长期"说法，写预计节点或不写）；②本周推进部分：具体任务（业务/开发/测试/重构/优化）+ 完成了没有（没完成补时间点）+ 达到什么效果（**必须带数字口径**，模板示例："直通率约为100%（100/100张图）"；测试数量少要注明）+ 存在问题（**只写自行解决中的问题；"需协助"类原则上不写**，走日常对接——SKILL.md"对外口径两不写"条；"完全没做不要写"）；③指派人员栏=项目负责人写（**我方是被指派方，不写**）。**写业务进展，不点名交付物文件**（发给工程师/外包方的 PPT/报告一旦点名会被索要）。**周总结页的词全部自解释**（细项页才展开的代号/图号不许先出现）；写完按**四问自检**（项目经理视角）：能不能用、进度、方向偏没偏、预计何时可整合。
- 项目细项页（每项目 1~3 页，编号 一、二、三）：小标题行 = 编号+细项名+一句实情；**刚开发的介绍技术路线，开发中的介绍实际情况，且须同步把周总结里的时间周期与效果写到此页**；每页一个大配图框（12.1×5.0in）+ 图注 `图 N  xxxxx`（10pt）。
- 下周计划页：每项目一个花括号+项目标签（**花括号数量=开头写了几个项目**），条目格式 = 小标题（具体任务内容、预期达到效果、时间点）。

**样式（模板原样继承，不改造）**

- 正文字体微软雅黑 16pt 加粗 色 002060；图注 10pt 加粗 002060；目录词条汉仪旗黑-55简 24pt（字体随模板走，缺字体由查看端替换，不换成别的字体名）。
- 目录页、项目标签、花括号是**结构**不是装饰——不删不改版式（旧模板"朴素口径"三删规则不适用于 V2.0）。
- 填文本用首 run 替换保格式（presentations:pptx skill 模板继承流程；改模板副本不动原模板）。

**仍通用的内容纪律（从 C 节并入）**

- 新学的技术/工具/踩坑写进它所服务的项目条目；不新增节、不改节名。
- "预期达到效果"写成可验收的描述（"支持XX输出"而非"优化XX"）。
- 区间终点 = 周日的日期口径不变；封面日期行照模板用双横线。
- 闭环：上期"下周计划"的条目 → 本期周总结逐条给完成情况（真做了才写，出处=当周工作日志）。
- 去AI味扫描覆盖 ppt 全部文本（含表格 cell 的检查习惯保留）；数字带口径、结论带对比对象等"交付自包含"条照旧。
